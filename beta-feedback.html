How this works & the ground rules (open me first)

You're the independent beta tester for Agent Governor, a server-side traffic controller for an Agentforce / MIAW chat agent. Your job is to install it from the repo's README.md alone, exactly as a real adopter would, and report where you got stuck and whether each control works.

  1. Docs only. For the install use only the repo's README.md. Don't ask the author for help. If the README doesn't say how to do something, that's a finding — log it in the friction section and do your best to proceed.
  2. Log everything that isn't obvious in the friction section, with the README step it relates to. Friction is the most valuable thing you produce.
  3. Time-box it to ~60–90 minutes. Blocked >15 min on one step? Log it as a blocker and move on to what you can still test.
  4. Additive only / it's a real org. Only add things (the deploy, one config record, one Site). Don't delete or modify existing metadata.

Full instructions are in the Beta Test Packet the author shared. Test page for Part C Layer 2: mbonaddio-sfdc.github.io/pages/beta-test-page.html.
