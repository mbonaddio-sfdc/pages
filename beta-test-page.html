About sampling (read before testing the % dial). The first time you click Run check, the page rolls the dice once against the Sampling Rate and then remembers whether you were IN or OUT for the rest of this browser session. That's intentional — it mirrors a real visitor, so the agent doesn't flicker in and out on every page load.

The catch when testing: if you change Sampling Rate in Salesforce, clicking Run check alone will keep showing the old roll. Click Reset session sampling first, then Run check, to force a fresh roll against the new rate. (Clear / hide agent just blanks the panel — no effect on the roll.)
